# knf-dk.github.io
# KNF Consultancy Website

Dette repository indeholder den offentlige porteføljeside for KNF (Kristian Niels Frederiksen).
Siden er hostet via [GitHub Pages](https://pages.github.com/).

## Teknologi
- **HTML5** (Single-page struktur)
- **Tailwind CSS** (Hentes via CDN for instant styling)
- **Google Fonts** (Inter & JetBrains Mono)

## Sådan opdaterer du siden
Al konfiguration, styling og indhold ligger samlet i `index.html`. 
For at ændre tekst, farver eller tilføje nye cases, skal du blot rette direkte i `index.html` og lave en *git commit*. GitHub Pages vil automatisk bygge og udgive de nye ændringer.
